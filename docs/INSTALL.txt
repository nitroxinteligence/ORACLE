ORACLE 0.3 — macOS Apple Silicon

Abra Oracle.app. Para instalar, você também pode copiar Oracle.app para Aplicativos.
Esta é uma distribuição local de desenvolvimento, com assinatura ad hoc. Não foi notarizada pela Apple.

Primeiro acesso: cole o código recebido de Mateus, conecte o Codex, escolha a pasta original do Obsidian e revise a configuração. Instalar Oracle envia a skill ao Codex e acompanha verificações reais. Se uma etapa precisar de sua confirmação, a interface apresentará a solicitação. Cancelar conserva o que já foi confirmado; Retomar continua o mesmo plano.

A opção Editar salva o Markdown original da pasta escolhida. Rascunhos e cópias de recuperação ficam no perfil local do Oracle. Um conflito com uma edição externa exige revisão da nova base antes de salvar. O bloqueio protege a interface, sem criptografar o vault.

A licença é verificada offline. A instalação pelo Codex precisa de acesso normal à conta e internet. O código não possui revogação remota instantânea nem contagem central de assentos. A confiança de hooks continua sendo controlada pelo Codex.

Atualizações são verificadas sem instalar ao clicar em Verificar. Apenas uma versão aprovada e conferida habilita a ação de instalação. Personalizações dos documentos são preservadas pelo atualizador.
