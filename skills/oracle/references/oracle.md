# Oracle: contrato do produto

Oracle é o aplicativo macOS que instala um Second Brain no vault escolhido pelo usuário e permite explorar e editar conhecimento local. Os arquivos Markdown do Obsidian são canônicos; GBrain fornece o índice derivado. A interface organiza departamentos, especialistas e skills. A skill Oracle é instalada diretamente no Codex, fora do vault.

O onboarding prepara acervo, busca local e integração opcional com Codex. Hooks preparados, hooks confiados, agendamento registrado e execução verificada são estados diferentes. Captura de conversas depende dos hooks autorizados e do workspace correspondente; não captura automaticamente todos os chats do ChatGPT ou Codex. Manutenção e processamento remoto dependem dos consentimentos e capacidades configurados.

A manutenção pode criar índices com links para organizar o Graph View; não deve mover ou reescrever notas pessoais por rotina. Atualizações do acervo alteram somente arquivos gerenciados, preservando conteúdo do usuário e alterações locais. A skill não instala atualizações, cria agendamentos ou muda configurações por ter sido invocada.

Use os comandos e ferramentas realmente anunciados na sessão. GBrain/MCP é opcional para consultar Markdown. Se disponível, use busca limitada ao vault autorizado e confirme gravações nos arquivos originais. Arquivo de iCloud indisponível não equivale a exclusão. Não use credenciais do ChatGPT como chave de API e não presuma inferência offline ou integrações externas ativas.
