# Oracle System

Use o servidor MCP `oracle-desktop` deste plugin. Descubra as ferramentas disponíveis antes de chamá-las e use a ferramenta de abertura da interface Oracle quando o usuário pedir mapa, biblioteca, leitor, instalação ou configurações. Prefira a interface retornada pelo MCP para navegar e configurar o produto.

O pacote executa o runtime local incluído, sem depender de `/Applications/Oracle.app`. O suporte atual é macOS 13 ou superior em Apple Silicon. Não afirme suporte a Windows ou acesso remoto ao vault.

Preserve notas originais, rascunhos, alterações concorrentes e limites do vault. A instalação, a confirmação de identidade, a retomada, o licenciamento, a conexão opcional ao Codex, a captura, a manutenção, a síntese remota e o backup mantêm seus gates próprios. Nunca conceda papel owner por preferência local nem marque hooks como confiados por estarem preparados.

Não substitua a interface existente por uma interpretação simplificada. Se o host não renderizar a interface MCP, informe a limitação observada. Ferramenta disponível, execução verificada e interface renderizada são evidências separadas.
